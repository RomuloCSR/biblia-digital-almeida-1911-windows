# Bíblia Digital Almeida 1911 em PT-BR — Windows

Leitor bíblico leve, rápido e **100% offline** para **Windows**, baseado na edição **Almeida 1911 (Domínio Público)** com atualização ortográfica e gramatical realizada em **11/2026** para o Português do Brasil.

> **Nota editorial:** O conteúdo está em processo contínuo de atualização e pode eventualmente apresentar pequenas falhas ortográficas ou gramaticais. Colabore nos enviando seu feedback pela aba **Issues** deste repositório. Obrigado!

---

## Como baixar e ler no Windows (Sem instalar nada)

1. Clique no botão verde **`<> Code`** lá em cima e depois em **`Download ZIP`** (ou baixe pela aba **Releases** na lateral direita).
2. Extraia a pasta baixada no seu computador (clique com o botão direito no arquivo `.zip` -> **Extrair Tudo...**).
3. Abra a pasta extraída e dê **dois cliques** no arquivo **`motor.biblia.exe`**.

## Comandos dentro da leitura

* **`ENTER`** — Avança para a próxima página do capítulo.
* **`T` + `ENTER`** — Exibe o capítulo inteiro de uma só vez.
* **`0` + `ENTER`** — Volta imediatamente para o menu principal
* **`Ctrl` + roda do mouse** (ou `Ctrl` + `+` / `-`) — Aumenta ou diminui o tamanho da letra.

## Este aplicativo é seguro? (Sobre o aviso "O Windows protegeu o computador")

**Sim, 100% seguro.** Este é um projeto independente, gratuito e sem fins lucrativos, publicado em código aberto no **GitHub** (plataforma de referência mundial utilizada por desenvolvedores).

* **Por que o Windows SmartScreen exibe uma tela azul de aviso?** O Windows exibe esse alerta preventivo para qualquer programa novo que não tenha sido assinado por um certificado comercial pago nem publicado na Microsoft Store.
* **Como abrir tranquilamente:** Na tela azul do Windows, clique em **`Mais informações`** (logo abaixo do texto do aviso) e depois clique no botão **`Executar assim mesmo`**.
* **Transparência total (Código Aberto):** Todo o código-fonte deste aplicativo (`terminal.c` e a pasta `kernel`) e os textos dos 66 livros estão abertos e visíveis nesta página.
